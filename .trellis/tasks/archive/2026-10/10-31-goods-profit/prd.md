# ① 商品净利润与成本录入

## Goal

让商家把进货成本、包材、快递等拼多多不保存的成本录入 CLI，并按商品输出统计窗口内的净利润额和利润率，用来回答"ROI 2.5 的商品扣掉货本后到底赚不赚钱"。

父任务：`10-31-operating-data-gaps`。口径决策见 `docs/adr/0004-goods-profit-reporting-semantics.md`，术语见 `CONTEXT.md` 中的 Merchant Cost Entry 和 Goods Net Profit。

## Requirements

### R1 成本录入（Merchant Cost Entry）

- R1.1 新增 `pdd goods cost set | list | remove | import <file>`。成本按「账号 + 店铺 + 商品」保存，删除账号时级联删除。
- R1.2 每个商品可以录入一个默认成本，也可以按订单 `spec` 文本精确匹配，为某个规格单独录入覆盖值。
- R1.3 成本项包括：货本（按件）、包材（按单）、快递成本（按单），以及可选的固定单价项，如运费险保费、技术服务费（按单）。金额输入单位为元，规则和现有的 `--price-yuan` 一致。
- R1.4 每个成本项只保留当前值，并记录更新时间。
- R1.5 `import` 支持批量导入。格式错误时整批拒绝，并报告出错的行。

### R2 利润查询（Goods Net Profit）

- R2.1 新增 `pdd goods profit [--days 30] [--goods-id <id>]`。`--days` 取 1–90，默认 30，超出范围返回 exit 2。窗口为最近 N 个完整自然日（上海时区，不含当天）。订单按成团时间 `group_time` 落入窗口，和上游筛选参数 `groupStartTime/groupEndTime` 一致。输出各商品列表和全店合计 `summary`。
- R2.2 收入 = 实付金额 + 平台优惠。全店合计里单独输出 `platform_discount_yuan`。
- R2.3 退款成功的订单（`after_sales_status = 5`）按全额退款、货已退回处理：不计收入，不扣货本；已发货的照扣包材和快递，未发货的不扣。
- R2.4 售后处理中的订单（10/11）按正常订单计算，同时单独输出这类订单的单数和金额。
- R2.5 推广花费只扣 `promo.entityReport` 中能按 `goodsId` 归属到该商品的部分。店铺级推广花费只计入全店合计，不分摊到商品。全店推广花费取报表总计，店铺级花费 = 总计 − 商品归属合计，差值为负时置 null；hint 写明"仅含商品推广报表口径"。总计是否覆盖店铺关注、询单等计划，等有投放数据时再验证。
- R2.8 成本项允许为 0。运费险、技术服务费等可选按单项，遇到退款时和包材、快递规则相同：已发货照扣，未发货不扣。未付款取消的订单，收入和所有成本都记 0。
- R2.9 利润率 `gross_margin_pct`、`net_margin_pct` 是有符号百分数，可以为负，绝对值也可以超过 100，不做截断。这是通用 `_pct` 0–100 规则的例外。
- R2.6 只输出数值，例如 `net_profit_yuan`、`gross_margin_pct`。盈亏只体现为数值的正负，不输出保本 ROI，也不打亏损标签。
- R2.7 输出中带上所用成本的 `cost_updated_at`，以及因规格不匹配、回落到商品默认成本的订单数。

### R3 缺失与不完整

- R3.1 商品既没有默认成本也没有匹配的规格覆盖时，该商品的利润和利润率为 null。
- R3.2 推广数据拉取失败时，推广花费和利润为 null；拉取成功但没有该商品的记录时，推广花费为 0。
- R3.3 订单采集被截断或限流时，标记为数据不完整，并给出 hint。

## Acceptance Criteria

- [ ] 能用 `set` 和 `import` 录入成本，`list` 能看到，`remove` 能删除；删除账号后成本记录随之删除。
- [ ] fixture 场景覆盖：有成本、无成本（结果为 null）、规格覆盖命中、规格未命中回落、退款成功（已发货和未发货）、售后处理中、推广数据缺失（结果为 null）、推广无记录（结果为 0）。
- [ ] 输出中没有保本 ROI 或任何盈亏分类字段。
- [ ] 字段说明写明两项已知高估：仅退款不退货、需要商家共担的平台补贴活动。
- [ ] data 契约 v2 测试覆盖 `goods cost *` 和 `goods profit`。
- [ ] ADR 0004 状态改为 Accepted。
